## 一、项目背景与目标

### 1.1 什么是 FC6+6？

FC6+6（Forecast 6+6）是一种企业滚动预测模式：**前 6 个月为已完成的实际数据（YTD6），后 6 个月为预测数据（FC7-12）**。公司每半年编制一次，用于财务规划、资源配置与绩效管理。

### 1.2 系统名称

**TCSS**（Total Company Forecast Support System）—— 全公司 FC6+6 编制支持系统

### 1.3 建设目标

| 目标 | 说明 |
|------|------|
| 数据自动化 | 替代手工 Excel 汇总，自动采集 ERP、CRM、SFE 等系统数据 |
| 模型标准化 | 统一各 BU（业务单元）的预测逻辑和模板格式 |
| 版本管控 | 对每次编制过程中的数据、假设和文件进行版本管理 |
| 权限分级 | 业务录入 → 财务复核 → CEO 审批的多级审核流 |
| 可视化输出 | 自动生成管理报表、KPI 看板和风险提示 |

## 系统概述
FC6+6（Forecast 6+6）是企业半年度滚动预测系统。系统需支持：
- 收入、费用、人员编制（HC）、资本支出（Capex）和管理报表模块
- 数据采集、导入、可视化和报表自动生成
- 多用户、多角色的权限管控

## 五大核心功能

### 1. 数据采集与导入
- 支持从 ERP、CRM、SFE（销售力量效能）系统导入历史数据（YTD6 实际数）
- 支持 Excel 模板上传（.xlsx），按预设规则解析并存储数据
- 支持手工录入预测假设（FC7-12）
- 数据版本控制：每次修改生成快照，支持回溯历史版本

### 2. 预测模型引擎
系统包含以下预测子模型，每个模型可独立配置：
- **收入预测**：销售基础线 + 增长计划（现有业务增长 + 新业务增长）
- **费用预测**：维持性费用 + 新增费用（电商、HC C&B、包装测试等）
- **生产成本预测**：基于 BOM（物料清单）的成本还原模型，含直接人工、耗材、间接制造费用
- **HC 预测**：通过 HR 模块生成 FTE（全职当量）+ 薪酬福利（C&B）数据
- **Capex 预测**：仪器投放、自动化项目带来的效率提升和折旧预测

### 3. KPI 数据库与预警
- 内置 KPI 基准库：历史实际、年度预算、10年规划
- 对录入数据自动匹配 KPI 基准，超出阈值时发出预警
- 批准后数据锁定，不可修改

### 4. 多级审核工作流
- 业务部门：数据录入和修改权限
- 财务部门：数据复核和修改权限
- CEO：最终审批权限
- 审批后字段自动锁定，留存审计日志

### 5. 报表自动生成
- 按标准模板生成 Excel 文件（.xlsx），支持下载
- 自动分拆和合并管理报表科目
- 输出内容包括：
  - 公司级 FC6+6 关键绩效结果
  - 各 BU（市场营销、生产运营、研发技术、管理支持）的 KPI 报表
  - 同行业数据对比分析
  - 风险评估和改进建议

## 技术栈要求
- 前端：React + TypeScript + Tailwind CSS + ECharts（图表）
- 后端：Node.js + Express（或 FastAPI）
- 数据库：PostgreSQL（关系型数据）+ Redis（缓存）
- 文件处理：SheetJS（xlsx 读写）
- 认证：JWT + RBAC（基于角色的访问控制）

## 数据结构关键实体
- Company（公司）、BusinessUnit（业务单元）、ForecastVersion（预测版本）
- RevenueRecord（收入记录）、ExpenseRecord（费用记录）
- ProductionCost（生产成本）、HCPlan（人员计划）、CapexPlan（资本支出计划）
- KPIBenchmark（KPI 基准）、AuditLog（审计日志）、ApprovalRecord（审批记录）

## 三、业务数据架构详解

### 3.1 市场营销模块 — 数据流

```
销售预测 = 销售基础线 + 销售增长计划
           ↓                    ↓
    【YTD6 历史数据】      【增长输入数据】
    - ERP YTD6            - SFE（现有业务）
    - CRM YTD6            - 仪器投放计划
    - 前一期预测数         - 增加销售HC计划
    - 去年实际数           - 其他新增目标
           ↓                    ↓
    【FC7-12 预测数据源】  【新业务增长数据】
    - 经销商经销存         - 电商投流
    - CRM预测              - POCBio预测
    - 年底囤货计划         - 预测毛利率
```

**各 BU 预测模型：**

| BU | 收入模型 | 费用模型 |
|----|---------|---------|
| 国内人医 | 产品结构和毛利预测 | BU部门费用 |
| 电商 | 产品结构和毛利预测 | BU部门费用 |
| 国际人医（公卫/非公卫） | 标单、常规单、产品线毛利 | BU部门费用 |
| 宠物 | 产品结构和毛利预测 | Capex和部门费用 |

**统一输出：**
- 产品线和 SKU 7-12 月基础销量与收入
- 产品线和 SKU 增长计划增量与收入
- 利润中心 EBIT 预测和对比
- 运营资金 DSO 预测

---

### 3.2 生产运营模块 — 数据流

```
生产成本预测
    ├── 库存策略数据（ERP YTD6 历史产量 + 实际成本）
    ├── 生产预测数据（SKU 7-12月份产量、预测周转天数、得率、OEE）
    ├── 采购数量计划
    │     ├── 完全变动成本
    │     │     ├── 北京内部材料
    │     │     └── 外购材料
    │     └── 制造成本动因
    │           ├── 直接人工
    │           ├── 耗材和生产费用
    │           ├── 能源
    │           ├── 质检
    │           └── 间接制造费用（租金、折旧和摊销）
    └── 降本/自动化项目
          ├── 材料降本
          ├── 人工效率提升
          └── 自动化带来的效率提升和Capex折旧
```

**各生产基地预测模型：**

| 基地 | 模型类型 |
|------|---------|
| 厦门/长汀 | BOM和成本还原预测、变动成本、其他费用、库存和Capex折旧 |
| 北京（原料） | BOM预测、变动成本、其他费用、库存和Capex折旧 |
| 苏州（仪器） | BOM和成本还原预测、变动成本、其他费用、库存和Capex折旧 |
| 苏州（试剂） | BOM和成本还原预测、变动成本、其他费用、库存和Capex折旧 |
